# CPF Validator & Generator (Manual)

Projeto em **Python** que contém dois scripts:  
um **gerador de CPF fictício válido** e um **validador de CPF** desenvolvido manualmente, sem o uso de bibliotecas externas.

---

##  Funcionalidades

- **Gerar CPF:** cria números de CPF válidos aleatórios (11 dígitos).
- **Validar CPF:** confere se um CPF inserido é válido conforme os dígitos verificadores.
- Algoritmo manual, sem dependências externas.
- Código limpo e comentado — ideal para estudos.
